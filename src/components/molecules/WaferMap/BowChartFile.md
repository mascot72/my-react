# BowChartFile.tsx 웨이퍼 맵 시각화 컴포넌트 개념 및 도식화

## 1. 개념 요약

이 코드는 반도체 웨이퍼 맵을 SVG 기반으로 시각화하는 React 컴포넌트입니다.  
측정 포인트, 측정값, 히트맵, DieMap(격자), 분포 곡선 등 다양한 정보를 한 화면에 표현합니다.

---

## 2. 동작 흐름 도식화

### (1) 전체 구조

```
+---------------------------------------------------+
| [상단 축 라벨]                                    |
|                                                   |
|  +---------------------------------------------+  |
|  | [좌측 축]   [격자]                          |  |
|  |             +---------------------------+   |  |
|  |             |   원형 웨이퍼 영역        |   |  |
|  |             |   - 히트맵(컬러 원)      |   |  |
|  |             |   - DieMap(격자)         |   |  |
|  |             |   - 측정 포인트/값       |   |  |
|  |             +---------------------------+   |  |
|  +---------------------------------------------+  |
|                                                   |
| [하단 그래프: 측정값 분포 곡선]                    |
+---------------------------------------------------+
```

### (2) 주요 시각화 요소

#### [A] SVG 격자(Grid)

- 웨이퍼 영역 전체에 10x10 간격의 선을 그림

#### [B] 원형 웨이퍼 영역

- 중심 (50,50), 반지름 45의 원형 클리핑
- 내부에 히트맵, DieMap, 측정 포인트/값 표시

#### [C] 히트맵(Heatmap)

- 측정 포인트 기반 보간값을 원형 영역 내 일정 간격으로 계산
- 각 위치에 컬러 원(circle)로 표현 (blur 필터 적용)

#### [D] DieMap(격자)

- 원형 영역 내 사각형 격자(rect)로 평균값을 색상으로 표시

#### [E] 측정 포인트 및 값

- 랜덤 위치의 측정 포인트(circle)와 값(text) 표시

#### [F] 하단 그래프(측정값 분포)

- 측정 포인트 위치와 값을 기반으로 곡선(path)과 색상 그라데이션(linearGradient)으로 표현

#### [G] 컨트롤 패널

- 측정 포인트/값/DieMap 표시 여부를 체크박스로 선택 가능

---

## 3. 주요 알고리즘 및 처리

- **측정 포인트 생성**  
  원형 영역 내 랜덤 위치와 값으로 포인트 배열 생성

- **거리 기반 보간**  
  각 grid 위치에서 측정 포인트와의 거리, 값에 따라 보간값 계산

- **색상 결정**  
  값의 상대적 위치에 따라 hsl 색상으로 변환

- **SVG 필터(blur)**  
  히트맵 원에 블러 필터 적용해 부드러운 컬러 분포 연출

- **DieMap 평균값**  
  각 격자 영역 내 grid 값의 평균을 구해 색상으로 표시

## 6. 요약

측정 포인트, 보간 기반 히트맵, 격자 평균값, 분포 곡선 등 여러 시각적 요소를 결합하여
